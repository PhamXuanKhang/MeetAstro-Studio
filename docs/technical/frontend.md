# Frontend — Electron Desktop App

Current submit frontend: `electron-app/` (Electron + React + TypeScript + Vite).

Flet was an early prototype path and is not the active submission frontend.

---

## Responsibilities

The Electron app provides:
- Supabase email/password and OAuth auth flows
- Meeting creation, audio/video upload, and live recording entry points
- Pipeline progress screens
- Transcript review before analysis
- Analysis results and action-item review
- Jira provider settings and push flow
- Meeting history and revisit flow

---

## Project Structure

```text
electron-app/
├── electron/                  # Electron main process and IPC
├── python/                    # Python sidecar packaging for local recording
├── src/
│   ├── api/                   # Axios FastAPI clients + Supabase data clients
│   ├── auth/                  # Supabase auth adapter + deep-link handling
│   ├── components/            # Shared UI components
│   ├── hooks/                 # Job polling, recording, Supabase hooks
│   ├── store/                 # Zustand app/auth state
│   ├── styles/                # Design tokens and global CSS
│   └── views/                 # Route-level screens
├── package.json               # Vite/Electron build config
└── public/                    # Static app assets
```

---

## Runtime Pattern

```text
Electron renderer
  -> Supabase JS SDK for auth and direct user-owned table views
  -> Axios FastAPI client for upload, jobs, AI processing, settings, and Jira push
  -> Electron IPC / Python sidecar for local recording support
```

The backend remains the authority for heavy processing and integrations. The renderer should not use service-role Supabase credentials.

---

## Main Screens

- `src/views/auth/*`: login, register, forgot/reset password
- `src/views/DashboardView.tsx`: recent meetings overview
- `src/views/NewMeetingView.tsx`: record/upload entry point
- `src/views/ProcessingView.tsx`: job progress
- `src/views/ReviewTranscriptView.tsx`: transcript review before analysis
- `src/views/ResultsView.tsx`: summary/results
- `src/views/ReviewView.tsx`: action-item review and Jira push
- `src/views/HistoryView.tsx`: past meetings
- `src/views/SettingsView.tsx`: OpenAI/Jira provider settings

## Commands

```bash
cd electron-app
npm install
npm run dev
npm run typecheck
npm run build
```

Production Windows output is an EXE installer generated by `electron-builder` and published as `MeetAstro-Setup-*.exe`.
